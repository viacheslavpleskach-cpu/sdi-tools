### 4. Завантаження на Google Диск
- `create_file`:
  - `title` = назва файлу;
  - `parentId` = id підтеки «Зміни стану розгляду — ретро»;
  - `contentMimeType` = `application/x-xz` (для `.json` — `application/json`);
  - `disableConversionToGoogleType` = true;
  - `base64Content` = посилання на файл `sha256:<sha256sum файлу>:<абсолютний шлях>`. Вміст **не** вставляти в розмову.
- Кожне завантаження інспектор підтверджує в чаті.
- Якщо завантаження відхилено через розмір — надіслати файл через SendUserFile і попросити інспектора покласти його в підтеку вручну.
