# sdi-tools

Скрипти й дані проєкту «СДІ» (підготовка висновків за результатами попередньої перевірки дисциплінарних скарг, ухвал 3ДП, правок редактора, роботи з відкритими даними судів). Автор: В'ячеслав Плескач.

Репозиторій замінює копії скриптів, CSV і шаблонів у документах проєкту claude.ai: у сесії їх не треба читати з проєкту чи переписувати, достатньо склонувати репозиторій.

## Початок роботи в новому середовищі

```bash
git clone --depth 1 https://github.com/viacheslavpleskach-cpu/sdi-tools && cd sdi-tools
bash get.sh        # edrsr_vybirka.py з edrsr-tool + check; посилання на реєстр ВП ВС, якщо поруч є клон postanovi
```

Скрипт ЄДРСР тут не зберігається: єдина копія — публічний репозиторій [edrsr-tool](https://github.com/viacheslavpleskach-cpu/edrsr-tool) (`edrsr.py`); його використовують і скіл «edrsr-court-decisions», і `get.sh` (зберігає як `edrsr_vybirka.py`). Зміни вносити лише там.

Реєстр та індекс постанов ВП ВС ведуться в репозиторії `postanovi_VP-VS-monitoring` (тека `indeks`; щодня оновлює дайджест). Для `praktyka_poshuk.py --vpvs` склонуйте його поруч і запустіть `get.sh` або передайте `--reg-vpvs <шлях>`.
